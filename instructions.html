Ledger

← Back to Ledger

Load any number of finished singings and get one combined record plus real totals across all of them — what's been sung most, from which books, and by which leaders. Nothing here edits anything; it only reads and adds up.

Quick Start

  1. Open index.html and choose or drop in as many CSV files as you like — Simple Minutes exports, Simple Compile source files, or Master CSVs from the full Minutes app all work, and can be mixed freely.
  2. Check the loaded-singings list for anything flagged as a likely duplicate.
  3. Read the totals: Song frequency, By book, and By leader.
  4. Download combined CSV for one file with every song from every singing, or Download totals CSV for the three tables as their own file.

What Counts as a File It Can Read

Any real Schema 5 Singing Record — the same CSV format every app in this suite reads and writes. That covers a Simple Minutes export, a file exported from Simple Compile's own source, or a Master CSV downloaded from the full Minutes app, at any stage of that singing being worked on. A file that isn't a Singing Record at all (the wrong file entirely, or one with no Event or Date column) is rejected with a plain message rather than silently producing wrong totals.

Loading Singings

  • Select several files at once from the file picker, or drop them on the page together — there's no one-at-a-time requirement.
  • Every file loaded appears in a running list: event, date, location, and how many songs it contributed. Tap Remove to take one back out.
  • Tap Reset all to clear every loaded singing at once and start over — it asks for confirmation first, since there's nothing saved to bring it back afterward.
  • Nothing is uploaded anywhere. Each file is read once, in the browser, and its songs are added to memory for this session only — reopening the page starts empty again.

Duplicate Detection

Loading the same singing twice — the same file by mistake, or its Event ID matching one already loaded — is flagged rather than silently double-counted. A flagged row still appears in the list, but its songs are left out of every total and out of both exports, until you tap Include anyway on that row. That's there for the real but rare case of two genuinely different singings that happen to share a name and date.

Reading the Totals

  • Song frequency — every song, grouped by title and book, sorted by how many times it's appeared across every singing loaded. The same tune logged from two different books' editions is counted separately, since a page or a title can genuinely differ between them.
  • By book — total songs sung from each tunebook, across every singing loaded. Book names are resolved from the suite's own tunebook data where possible, so this reads as "The Sacred Harp: 1991 Edition," not a bare code.
  • By leader — total songs led by each person, across every singing loaded. A song with more than one leader on file counts once for each of them. Songs from a leaderless file (a Simple Minutes log, most commonly) show under "(no leader listed)" rather than being dropped.

Exporting

  • Download combined CSV — every song row from every singing loaded, in one Schema 5 file. It's songs only, not a re-playable session log, so it's meant for review and reference, not reopening as a singing to edit.
  • Download totals CSV — the same three tables shown on screen, as one file with a labeled section per table, ready to open in a spreadsheet.

If Something Needs Fixing

Ledger has no editing surface at all. If a name, page, or book needs correcting in one of the singings before it's totaled, fix it in the full Minutes app first, then load the corrected file here.

Troubleshooting

A file won't load

Check that it's a real Schema 5 CSV — exported from Simple Minutes, Simple Compile, or Minutes, not a file that's been reformatted in a spreadsheet program along the way, which can rename or reorder columns.

My totals look too high

Check the loaded-singings list for a duplicate that was included by mistake, or two files that are really the same singing exported at two different stages (a Simple Minutes log, and later the same singing's Master CSV from Minutes) — load only one of those per singing.

A leader I know led songs isn't showing up, or shows as two different people

Ledger reads names exactly as they're spelled in each file. If the same person is logged under two spellings across different singings, merge the name variants in the full Minutes app before exporting, then reload the corrected file here.
